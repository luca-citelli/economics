# Report T04 — Governo, Tesoro e debito pubblico

Data: 28 settembre 2026. Profilo: `configs/t04.yaml` (1.000 persone, 33 imprese, 3 banche). Implementati fiscalità salariale e societaria, conto Tesoro e settlement verso depositi/riserve, acquisti pubblici nel matching, asta uniforme di bond zero coupon, costo ammortizzato, rimborsi e default sovrano controllato. Contratti e parametri in [t04_contracts.md](../technical/t04_contracts.md).

Ambiente: Windows, Python 3.11.9, `uv` 0.7.5. Verifiche concluse con exit code 0: `uv run --offline --locked ruff check src tests`; `uv run --offline --locked ruff format --check src tests`; `uv run --offline --locked pytest -q` (**105 test passati**); `uv run --offline --locked economic-sim validate configs/t04.yaml`; `uv run --offline --locked economic-sim run configs/t04.yaml --steps 53 --csv runs/t04-53.csv --output runs/t04-53.json`; `uv build --offline` (wheel e sdist 0.4.0); `git diff --check`. La prima verifica online di `uv run` non ha potuto ottenere il certificato TLS di PyPI; le verifiche successive sono state completate con cache offline e lockfile.

Revisione economica: emissione da un titolo di apertura detenuto dalla BC, spesa che accredita depositi/riserve dei venditori, tasse che tornano al Tesoro, asta della settimana 52 e rimborso del titolo iniziale. Nel run da 1.000 persone, la settimana 1 ha 1.440 UM di `G` e 4.716 UM di trattenute salariali; nella settimana 2 sono stati pagati 8.505,509365 UM di imposta sui profitti maturata. Alla settimana 52 sono stati offerti e collocati 1.338.424 UM nominali di nuovi bond a 0,95, con incasso di 1.271.502,8 UM; sono stati rimborsati 1.582.975,317847 UM del titolo iniziale. Alla settimana 53 il nuovo debito mostra 1.338.424 UM nominali e 1.272.757,641242 UM contabili, dopo l'accrescimento settimanale. Il PIL produzione/spesa differisce di 0 UM nelle 53 settimane; arretrati sovrani 0 UM. `test_treasury.py` verifica anche asta parziale/zero, budget, pareggi, formazione adattiva dei rendimenti privati, premi/sconti, garanzia a scadenza, rollback e default controllato senza cassa negativa.

Limiti: la sequenza di domanda/produzione mostra ancora il calo di attività già diagnosticato in T02/T03; nessuna validazione macroeconomica è dichiarata. Mancano mercato azionario primario, crisi di imprese/banche e dividendi (T05), oltre a runner/API, checkpoint e UI (T06/T07). L'ordine BC configurato nel profilo T04 è un intervento stilizzato di laboratorio, non una regola BCE.
